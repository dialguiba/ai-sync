# Domain Docs

This repository uses one domain context.

Before exploring a feature, read the root `GLOSSARY.md` if it exists and relevant ADRs in `docs/adr/`. Use glossary terms in issue titles, proposals, and code discussions. Flag any conflict with an existing ADR.

Create `GLOSSARY.md` when the first domain term is agreed and an ADR when a decision needs recording. Their absence does not block other work.
